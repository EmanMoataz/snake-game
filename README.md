# 🐍 Snake Game – Python

A simple Snake Game built using **Python** and **Pygame**.

## 📌 Features

- Snake movement using arrow keys
- Random food generation
- Snake growth after eating food
- Wall and self-collision detection
- Game Over screen
- Play Again and Quit options

## 🛠️ Technologies & Concepts Used

- Python
- Pygame
- Functions and Loops
- Lists
- Keyboard Event Handling
- Random Number Generation
- Collision Detection

## 📂 Project Structure

```text
Snake-Game/
├── snake_game.py
└── README.md
```

## ▶️ How to Run

1. Install Python 3.
2. Install Pygame:

```bash
pip install pygame
```

3. Run the game:

```bash
python snake_game.py
```

## 🎮 Controls

| Key | Action |
|---|---|
| Arrow Keys | Move the snake |
| C | Play Again |
| Q | Quit |
